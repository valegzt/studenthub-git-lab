# Contributing Guide

Gracias por tu interés en contribuir a StudentHub.

## Flujo de trabajo

1. Crear una rama a partir de `main`.
2. Realizar los cambios necesarios.
3. Hacer commits siguiendo convenciones claras (`feat:`, `docs:`, `fix:`).
4. Publicar la rama con `git push`.
5. Abrir un Pull Request describiendo los cambios.
6. Esperar revisión antes de integrar a `main`.
